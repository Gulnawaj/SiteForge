# 🚀 SiteForge — AI Website Builder

SiteForge is a full-stack AI-powered website builder that lets users create websites using natural-language prompts.

## ✨ Features

- 🤖 AI website generation
- ✏️ AI-powered website editing
- 🔐 Authentication & OTP verification
- 🔑 Forgot/reset password
- 📁 Project management
- 🌎 Community publishing
- ❤️ Likes & view tracking
- 💳 Credit-based AI generation
- 💰 Stripe payment integration
- 🐙 GitHub website export
- 📊 User contribution tracking

## 🛠️ Tech Stack

**Frontend**
- React
- Vite
- React Router
- Axios
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Nodemailer

**Integrations**
- AI API
- Stripe
- GitHub API
